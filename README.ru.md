# Zashita — помощник для защиты на русском языке

[简体中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

**[Открыть Zashita](https://russian-defense-ipad-unlasting.docileemu11.chatgpt.site)** · Веб-приложение / PWA · Версия 0.1.2

Zashita помогает готовиться к очной защите работы на русском языке и следить за ходом обсуждения. Приложение расшифровывает речь, выделяет вопросы с учётом недавнего контекста, находит подходящие фрагменты в ваших материалах и предлагает ответы с переводом на китайский.

Это русская версия описания проекта и инструкции. Интерфейс приложения пока на китайском языке; вопросы и ответы выводятся на русском и китайском.

Для доступа по публичной ссылке не нужен аккаунт GPT или постоянно включённый компьютер. Каждый пользователь указывает собственные API-ключи Alibaba Cloud Model Studio (Bailian) и DeepSeek. Для распознавания речи и генерации ответов нужен интернет; провайдеры могут взимать плату за запросы.

## Возможности

- **Расшифровка русской речи.** Звук с микрофона планшета передаётся через WebSocket-сервис сайта в Qwen ASR.
- **Выделение вопросов по контексту.** DeepSeek получает последние реплики и объединённые фрагменты речи. Система может распознавать вопросы без вопросительного знака и восстанавливать сокращения, если это позволяет контекст.
- **Русско-китайские ответы.** Вопросы и предлагаемые ответы сопровождаются переводом на китайский. В настройках можно указать пожелания к ответам.
- **Локальная библиотека материалов.** Загрузите PDF с текстовым слоем, DOCX, TXT в UTF-8 или Markdown. Перед генерацией ответа приложение подбирает относящиеся к вопросу фрагменты.
- **Очередь вопросов.** Новые вопросы не заменяют ответ, который вы читаете. Переключайтесь на следующий вопрос, когда будете готовы.
- **Сохранение настроек и ключей.** Настройки сохраняются в браузере, а для API-ключей предусмотрена отдельная кнопка сохранения на текущем устройстве.
- **Работа в браузере планшета.** Приложение разработано для iPad и может работать в совместимых браузерах Android-планшетов. Работу микрофона необходимо проверить на конкретном устройстве.

## Как начать

1. Откройте публичную ссылку в браузере планшета. На iPad используйте Safari. Вход в аккаунт GPT не требуется.
2. При желании добавьте приложение на главный экран. На iPad выберите **«Поделиться» → «На экран “Домой”»**. Настраивайте ключи и загружайте материалы в том браузере или установленном веб-приложении, которым собираетесь пользоваться: их локальные хранилища могут различаться.
3. Откройте **настройки (设置)**. Введите **API-ключ Bailian (百炼 API Key)** и **DeepSeek API Key**. Выберите регион, соответствующий ключу Bailian: материковый Китай / Пекин или международный / Сингапур.
4. Нажмите **«Сохранить ключи» (保存密钥)** и дождитесь подтверждения. При следующем открытии в том же браузере ключи восстановятся автоматически. Несохранённые изменения остаются только на текущей странице. Кнопка **«Удалить сохранённые ключи» (清除已保存密钥)** удаляет их из локального хранилища.
5. В разделе **«Материалы» (资料库)** загрузите работу, текст выступления или список терминов. Можно начать и без документов — ответы будут носить общий справочный характер.
6. Подключите микрофон и разрешите доступ к нему. Когда говорит преподаватель, выберите **«Вопрос преподавателя» (老师提问)**; когда отвечаете вы — **«Я отвечаю» (我在回答)**. Это ручное переключение ролей при использовании одного микрофона, а не автоматическое определение говорящего.
7. Прочитайте текущий ответ и затем выберите следующий вопрос. Пропущенный вопрос можно выделить из расшифровки или ввести вручную.
8. Регулярно экспортируйте резервную копию в JSON. Материалы и записи защиты хранятся в текущем браузере и не синхронизируются между устройствами.

Во время записи держите страницу открытой на переднем плане. Переключение в другое приложение, блокировка экрана или прерывание аудио могут приостановить запись; после возвращения подключите микрофон заново. Приложение не записывает системный звук других приложений.

## Материалы и поиск

| Формат | Требования |
| --- | --- |
| PDF | Текст должен выделяться; не более 250 страниц. Сканированные документы сначала нужно обработать с помощью OCR. |
| DOCX | Из документа извлекается текст. |
| TXT / Markdown | Кодировка UTF-8. |
| Любой загружаемый файл | Не более 20 МБ на файл. |

Веб-версия использует локальный поиск BM25 с нормализацией русских слов, разбиением китайского текста на пары символов и поисковыми запросами на русском и китайском, которые формирует модель. Локальные модели Whisper и модель эмбеддингов из настольной версии не загружаются. Сверяйте предложенные ответы с текстом своей работы и указанными фрагментами источников.

## Данные и API-ключи

- Публичная ссылка открывает доступ к программе, а не к личным материалам и истории других пользователей.
- Документы, расшифровки, настройки и сохранённые ключи относятся к локальному хранилищу конкретного устройства и браузера. Они не привязаны к аккаунту GPT.
- Ключи шифруются с помощью AES-GCM и хранятся в IndexedDB вместе с неизвлекаемым ключом Web Crypto. Это локальное хранилище браузера, а не «Связка ключей» iOS или межустройственная синхронизация. Приложение может расшифровать сохранённые ключи для выполнения запросов.
- API-ключи не включаются в экспортируемую резервную копию JSON. Очистка данных сайта удаляет локальные документы, записи, настройки и сохранённые ключи.
- Аудио в реальном времени передаётся в Alibaba Cloud. Вопросы, недавний контекст и подходящие фрагменты материалов передаются в DeepSeek. Введённые пользователем ключи проходят через сервис сайта для соответствующих запросов к провайдерам. Worker не хранит долговременные копии аудио, работ, записей или ключей.
- Пользователи одного профиля браузера имеют доступ к одним и тем же локальным данным приложения. Перед передачей устройства при необходимости сделайте резервную копию и удалите сохранённые ключи.

## Разработка

Установите актуальную версию Node.js, совместимую с закреплёнными зависимостями, затем выполните:

```sh
npm ci
npm run build
npm test
node scripts/preview.mjs
```

Для локальной проверки без записи микрофона и платных обращений к моделям:

```sh
node scripts/preview.mjs --mock
```

Тестовый сервер с имитацией провайдеров используется только локально и не входит в опубликованный Worker.

| Путь | Назначение |
| --- | --- |
| `src/client.mjs` | Интерфейс, состояние приложения, обработка расшифровки и очередь вопросов |
| `src/audio.mjs` | Захват звука с микрофона и обработка аудио |
| `src/backend.mjs` | Ретрансляция Qwen и запросы DeepSeek |
| `src/core.mjs` | Правила выделения вопросов, нормализация, поиск и ресэмплинг PCM |
| `src/files.mjs`, `src/pdf-text.mjs` | Импорт документов и чтение PDF с учётом совместимости Safari |
| `src/store.mjs`, `src/credentials.mjs` | Хранилище IndexedDB и шифрование API-ключей |
| `scripts/assemble.mjs` | Упаковка клиентского кода, значков и средств чтения PDF в Worker |
| `scripts/build.mjs` | Создание артефакта для развёртывания |
| `tests/` | Проверки правил, протоколов, хранения, импорта и работы в браузере |

## Развёртывание и сопровождение

Текущая рабочая версия размещена через Sites как единый пакет Cloudflare Worker ESM. Результат сборки — `dist/server/index.js` и `dist/.openai/hosting.json`.

Файл `.openai/hosting.json` содержит идентификатор существующего сайта. Сохраняйте его при обновлении этого же развёртывания. Используйте процесс работы с исходным кодом Sites: зафиксируйте и отправьте нужный коммит, затем опубликуйте архив, собранный именно из него. Для отдельной копии потребуется собственная настройка хостинга и HTTPS для доступа к микрофону. Одного клонирования GitHub-репозитория для публикации приложения недостаточно.

Перевод документации не меняет язык интерфейса работающего приложения и настройки языка ответов модели.

## Проверки и ограничения

Выпуск прошёл 16 автономных тестов: русские вопросы, восстановление сокращений по контексту, ресэмплинг, устранение повторов окончательной расшифровки, сохранение текущего ответа в очереди, поиск, протоколы провайдеров, совместимость потокового чтения PDF и сохранение зашифрованных ключей.

Браузерные проверки охватывали размеры экранов планшетов и телефонов, импорт настоящих PDF/DOCX/TXT, передачу контекста и фрагментов в имитированные запросы к моделям, чтение офлайн, резервные копии, настройки и сохранение/восстановление/удаление ключей. В тестах использовалась имитация провайдеров: реальный звук не записывался, платные запросы не выполнялись. Микрофон физического планшета, доступ к провайдерам и работу в реальной сети нужно проверить на целевом устройстве. Целевая версия для Safari/PWA — iPadOS 17 и новее.
